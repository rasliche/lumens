# Lumens

Lumens is the missing Nuxt-based Learning Management System. It's goal is to be convention and code first, but also instructor friendly.

There is a long roadmap ahead but this is a passion project I am going to continue to work on and evolve in my free time. In the end, this should be a simple, safe, easy-to-use, and welcoming product for non-profits and governments to deploy with minimal cost and outside support needed.

Look at the [Nuxt documentation](https://nuxt.com/docs/getting-started/introduction) to learn more.

## Setup

Make sure to install dependencies:

```bash
# npm
npm install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# npm
npm run dev
```

## Production

Build the application for production:

```bash
# npm
npm run build
```

Locally preview production build:

```bash
# npm
npm run preview
```

Check out the [deployment documentation](https://nuxt.com/docs/getting-started/deployment) for more information.
